# Advaith Panduga Portfolio

Complete source of your current portfolio. Built with HTML, CSS, and vanilla JavaScript; no installation or build step is required.

## Run
Extract this ZIP, then double-click index.html to open it in a browser.
Alternatively, in this folder run `python -m http.server 8000` and open http://localhost:8000.

## Edit
- index.html: page content, styles (inside <style>), and mobile menu JavaScript (inside <script>).
- advaith-portrait.jpeg: profile photo.
- Advaith_Panduga_Resume.pdf: downloadable resume.
Keep these files in the same folder so the photo and resume links work.

## Publish
Upload this folder to a static website host, or put it in a GitHub repository for deployment. No framework or build command is required; index.html is the entry point.

The contact buttons use email and phone links; there is no backend or contact-form service. This export does not contain ChatGPT hosting credentials or configuration.
